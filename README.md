The chat app start by registering the user - requesting the username that contains an underscore and is not more than 5 characters 
                                           - requesting the password that contains atleast 8 characters , 1 capital letter , 1 number and 1 special character
                                           - requesting the cell phone number that starts with +27 a South African code and has no more than 12 characters

Then after the user registered we asked for the user to login again if any of the details entered are incorrect it will say "try again" else it will say " Welcome +username+ , It's nice to have you again"
